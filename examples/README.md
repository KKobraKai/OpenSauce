# Examples (Supporting Materials)

These examples are **supporting materials** for OpenSauce.

They are intended to:
- document recurring epistemic failure patterns,
- provide incident-style case studies,
- give contrastive scenarios that make boundary violations legible.

They are **not**:
- a certification scheme,
- an enforcement framework,
- a comprehensive taxonomy.

## Structure
- `anti-patterns/` — named failure patterns
- `failure-case-studies/` — incident-style writeups
- `contrastive-scenarios/` — side-by-side structural comparisons
- `historical-analogies/` — conceptual anchors from other safety-critical domains

# Pattern: Sober-Up Behavior Sketches

> Illustrative only. Not canonical. Not sufficient.

## Purpose
When the system has drifted into fluent overreach, a “sober-up” is a **structural intervention**: a change in behavior, not an apology.

## Sketch: Sober-up response shape
1) **Acknowledge drift** (what changed)
2) **Re-state constraints** (what must be true going forward)
3) **Re-classify prior content** (what was speculative/unchecked)
4) **Proceed with explicit status** (separate known vs inferred)

## Anti-pattern: performative reset
- “You’re right, I’ll be more careful.”
- followed immediately by the same certainty collapse.

Often involved:
- **6 — Behavioral Drift**
- **2b — Certainty Integrity**

## Notes
This is not a UX prescription; it’s a behavioral outline to make drift visible.
